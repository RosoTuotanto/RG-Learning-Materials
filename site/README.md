# site

The generated GitHub Pages viewer site. Each game is a folder under `games/` (`games/2-nopeustesteri/`, ...) with one page folder per version: `games/<game>/versio-N/` and `games/<game>/versio-kotitehtavat/`. Each demo is a folder under `demos/` (`demos/feedback/`, ...). Shared images live in `assets/` (favicons sit at the site root). Any other folder at the site root is reported as a stray and ignored.

Each page folder holds an `index.html` (the viewer page), a `page.json` (its content), and an `app/` subfolder that the page iframes as `./app/index.html`. A version page's `page.json` lists its lessons as `lessons`, an array of `{ "title", "url" }` objects; a version that completes a lesson the LMS splits into parts lists every part.

Workflow:

- Drop each Solar2D HTML5 build output into the matching `app/` folder.
- Run `python tools/build_website.py` from the repo root. It regenerates the pages (including a `404.html`), patches every build in place, and reports missing or failed apps.

`page.json` files are the hand-editable page content. `index.html` files are generated by the builder; do not hand-edit them. The page templates and styles live in `tools/web-src/` (`base.html`, `styles.css`, `footer.html`, `landing.html`, `404.html`, and `site.json` for SEO config). The builder also emits `sitemap.xml` and `robots.txt`, and per-page SEO (canonical, Open Graph, Twitter card, JSON-LD) built from the single base URL in `tools/web-src/site.json`; the share image is `assets/og-image.png`. Change the deploy URL there in one place if the site ever moves.

GitHub Pages serves this folder through `.github/workflows/pages.yml`.

## Changes pages

Every version page with a previous version in `solar2d-projects/games/<game>/` gets a generated changes page at `games/<game>/<version>/muutokset/index.html`, linked from the version page's "Muutokset" line. `versio-kotitehtavat` is compared with the highest numbered version. `versio-0` exists only in `solar2d-projects/games/` as the base for `versio-1` and has no page.

The diff comes from `tools/version_diff.py`, tuned by `tools/web-src/diff.json` (excluded folders and files, map extensions, preview extensions, context lines, similarity thresholds). The page behaviour (view toggle, expanding hidden lines) lives in `tools/web-src/diff.js`, which is inlined only into these pages.

The pages offer unified and side-by-side views, and preview changed images and audio from copies the builder writes to `muutokset/tiedostot/vanha/` and `muutokset/tiedostot/uusi/`. The builder owns each `muutokset/` folder: it removes stale preview files, and removes the whole folder when a version no longer has a previous version.

The pages are `noindex`, carry no canonical, and are left out of `sitemap.xml`. Do not hand-edit them; the same `python tools/build_website.py` run regenerates them.

## Open Graph share images

`assets/og-images/` holds one 1200x630 neo-brutalist share image per page type: `etusivu.png` (frontpage), `peli-<game>.png` (each game, shared by all of that game's version pages), and `demo-<demo>.png` (each demo). They are generated by `python tools/generate_og_images.py` (Pillow), driven by `tools/web-src/og-images.json` (card set, output dir, per-type slug wording, colours, layout) with inputs in `tools/og-assets/`. `build_website.py` reads the same config and points each page's `og:image`/`twitter:image` at the matching file, falling back to the frontpage card (then `site.json`'s `ogImage`) when a specific card is missing. Regenerate after adding or renaming a game or demo, then re-run the site build.

## Fonts

The viewer self-hosts two open-source typefaces (woff2, Latin subset) under `assets/fonts/`, referenced from `tools/web-src/styles.css` via `{{basePath}}assets/fonts/`. Both are vendored from the [Fontsource](https://cdn.jsdelivr.net/npm/@fontsource/) packages at version 5.3.0 and licensed under the SIL Open Font License 1.1 (full text in `assets/fonts/LICENSE-Archivo.txt` and `assets/fonts/LICENSE-Inter.txt`).

- Archivo (weights 700, 800), headings. Copyright 2020 The Archivo Project Authors.
- Inter (weights 400, 600, 700), body text. Copyright 2016 The Inter Project Authors.
