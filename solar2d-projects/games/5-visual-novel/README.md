# Roso Noir -visual novel

Kurssin 5 (Narratiivi ja pelitaide) opetuspeli. Peli rakennetaan kurssin oppitunneilla vaihe vaiheelta, ja kukin `versio-N`-kansio sisältää pelin siinä tilassa, jossa se on tietyn oppitunnin lopussa.

Kansiot `versio-0` ... `versio-9` ovat pelin kehitysvaiheet oppituntien etenemisen mukaisesti.

`versio-kotitehtavat` sisältää ohjelmointikotitehtävien malliratkaisun, joka on toteutettu pelin viimeisimmän version päälle.
