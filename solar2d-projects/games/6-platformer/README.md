# Platformer

Kurssin 6 (Kentät, äänimaailma ja pelisuunnittelun haasteet) opetuspeli. Peli rakennetaan kurssin oppitunneilla vaihe vaiheelta, ja kukin `versio-N`-kansio sisältää pelin siinä tilassa, jossa se on tietyn oppitunnin lopussa.

Kansiot `versio-0` ... `versio-19` ovat pelin kehitysvaiheet oppituntien etenemisen mukaisesti.

`versio-kotitehtavat` sisältää ohjelmointikotitehtävien malliratkaisun, joka on toteutettu pelin viimeisimmän version päälle.

`extra-assets`-kansio sisältää lisäassetit, jotka lisätään peliin vasta myöhemmillä oppitunneilla: hattuäänet kansiossa `hatSFX` ja tutoriaalikentän lähdetiedostot kansiossa `tutorial-kentta` (katso `extra-assets/README.md`).
