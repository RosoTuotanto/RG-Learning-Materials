# Opetuspelit

Tämä kansio sisältää Roso Games -kurssien opetuspelien lähdekoodit ja assetit. Jokaisella pelillä on oma kansionsa ja jokaisella kehitysvaiheella oma `versio-N`-alikansionsa. Se on kokonainen Solar2D-projekti, joten voit avata pelin Solar2D Simulatorissa juuri siinä tilassa, jossa se on tietyn oppitunnin lopussa. Kun oppitunti on jaettu useaan osaan, versio vastaa viimeisen osan lopputilannetta.

Top-down-seikkailua lukuun ottamatta jokaisella pelillä on myös `versio-kotitehtavat`-kansio, jossa on kurssin ohjelmointikotitehtävien malliratkaisu toteutettuna pelin viimeisimmän version päälle.

Kurssien opetuspelit ja niiden kansiot:

- `2-nopeustesteri` - Nopeustesteri (kurssi 2: Pelinkehityksen alkeet), [pelaa selaimessa](https://rosotuotanto.github.io/RG-Learning-Materials/games/2-nopeustesteri/)
- `3-fysiikkapallo` - Fysiikkapallo (kurssi 3: Pelisuunnittelu ja prototyypittäminen), [pelaa selaimessa](https://rosotuotanto.github.io/RG-Learning-Materials/games/3-fysiikkapallo/)
- `4-pokeri` - Pokeri (kurssi 4: Käyttäjäkokemus pelisuunnittelussa), [pelaa selaimessa](https://rosotuotanto.github.io/RG-Learning-Materials/games/4-pokeri/)
- `5-visual-novel` - Roso Noir -visual novel (kurssi 5: Narratiivi ja pelitaide), [pelaa selaimessa](https://rosotuotanto.github.io/RG-Learning-Materials/games/5-visual-novel/)
- `6-platformer` - Platformer (kurssi 6: Kentät, äänimaailma ja pelisuunnittelun haasteet), [pelaa selaimessa](https://rosotuotanto.github.io/RG-Learning-Materials/games/6-platformer/)
- `7-top-down` - Top-down-seikkailu (kurssi 6: Kentät, äänimaailma ja pelisuunnittelun haasteet), [pelaa selaimessa](https://rosotuotanto.github.io/RG-Learning-Materials/games/7-top-down/)

Kaikki pelit ja niiden kehitysvaiheet ovat pelattavissa selaimessa [oppimateriaalien verkkosivustolla](https://rosotuotanto.github.io/RG-Learning-Materials/). Jokaisella versiolla on siellä oma sivunsa, josta pääset version oppituntiin, lähdekoodiin ja muutoksiin edelliseen versioon verrattuna.

Kunkin pelin oma `README.md` kertoo tarkemmin sen kehitysvaiheista.
