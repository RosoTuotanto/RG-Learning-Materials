# Nopeustesteri

Kurssin 2 (Pelinkehityksen alkeet) opetuspeli. Peli rakennetaan kurssin oppitunneilla vaihe vaiheelta, ja kukin `versio-N`-kansio sisältää pelin siinä tilassa, jossa se on tietyn oppitunnin lopussa.

Valmis peli ja jokainen sen kehitysvaihe ovat pelattavissa selaimessa [oppimateriaalien verkkosivustolla](https://rosotuotanto.github.io/RG-Learning-Materials/games/2-nopeustesteri/). Jokaisen version sivulta näet, mihin oppituntiin se kuuluu ja mitä koodissa muuttui edellisestä versiosta.

Kansiot `versio-1` ... `versio-8` vastaavat oppituntien lopputilanteita: Luodaan pelinappula, Luodaan useita pelinappuloita, Erotellaan data ja toiminnallisuus, Lisätään pelin gameplay loop, Seuraavan nappulan indikaattori, Oikein/väärin-mekaniikka, Indikaattorin hallinta ja Game Over sekä Pelin pisteytys ja loppuhiominen. `versio-7` kattaa myös sitä edeltävän oppitunnin New Game -tila ja pelitilat, jolla ei ole omaa kansiota. `versio-0` on tyhjä Solar2D-projekti (vaakasuunta, 960x640-sisältöalue ja tyhjä `main.lua`), josta oppitunnin 046 rakentaminen alkaa.

`versio-kotitehtavat` sisältää ohjelmointikotitehtävien malliratkaisun, joka on toteutettu pelin viimeisimmän version päälle.
