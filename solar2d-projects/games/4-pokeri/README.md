# Pokeri

Kurssin 4 (Käyttäjäkokemus pelisuunnittelussa) opetuspeli. Peli rakennetaan kurssin oppitunneilla vaihe vaiheelta, ja kukin `versio-N`-kansio sisältää pelin siinä tilassa, jossa se on tietyn oppitunnin lopussa.

Valmis peli ja jokainen sen kehitysvaihe ovat pelattavissa selaimessa [oppimateriaalien verkkosivustolla](https://rosotuotanto.github.io/RG-Learning-Materials/games/4-pokeri/). Jokaisen version sivulta näet, mihin oppituntiin se kuuluu ja mitä koodissa muuttui edellisestä versiosta.

Kansiot `versio-0` ... `versio-12` ovat pelin kehitysvaiheet oppituntien etenemisen mukaisesti.

`versio-kotitehtavat` sisältää ohjelmointikotitehtävien malliratkaisun, joka on toteutettu pelin viimeisimmän version päälle.
