# Fysiikkapallo

Kurssin 3 (Pelisuunnittelu ja prototyypittäminen) opetuspeli. Peli rakennetaan kurssin oppitunneilla vaihe vaiheelta, ja kukin `versio-N`-kansio sisältää pelin siinä tilassa, jossa se on tietyn oppitunnin lopussa.

Valmis peli ja jokainen sen kehitysvaihe ovat pelattavissa selaimessa [oppimateriaalien verkkosivustolla](https://rosotuotanto.github.io/RG-Learning-Materials/games/3-fysiikkapallo/). Jokaisen version sivulta näet, mihin oppituntiin se kuuluu ja mitä koodissa muuttui edellisestä versiosta.

Kansiot `versio-0` ... `versio-7` ovat pelin kehitysvaiheet oppituntien etenemisen mukaisesti. `versio-0` on tyhjä Solar2D-projekti, jossa on valmiina vain pelin aloituskuvat `images/`-kansiossa.

`versio-kotitehtavat` sisältää ohjelmointikotitehtävien malliratkaisun, joka on toteutettu pelin viimeisimmän version päälle.

`extra-assets`-kansio sisältää pelin ääniefektit, jotka lisätään peliin vasta kurssin aikana (katso `extra-assets/README.md`).
