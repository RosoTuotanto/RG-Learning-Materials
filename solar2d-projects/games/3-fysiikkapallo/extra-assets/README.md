# Fysiikkapallo: lisäassetit

Pelin assetit ovat jokaisen `versio-N`-kansion sisällä, ja `versio-0` sisältää ne assetit, jotka ovat pelissä mukana alusta asti. Tämä kansio sisältää lisäassetit eli tiedostot, jotka lisätään peliin vasta myöhemmällä oppitunnilla.

## Sisältö

- `bounce.wav`: ääni, kun pallo osuu tasoon.
- `score.wav`: ääni, kun pallo osuu maaliin.
- `reset.wav`: ääni, kun pallo resetoidaan.

Äänet lisätään peliin oppitunnilla "Lisätään peliin ääniefektit", ja ne ovat mukana versiosta 5 alkaen version `audio/`-kansiossa.
