# Feedback Demo

Two boxes shoot each other with pistols. The same fight replays across seven versions, and each one changes a layer of feedback on a mechanic that never changes.

Try it in the browser on the [learning materials site](https://rosotuotanto.github.io/RG-Learning-Materials/demos/feedback/).

The points the demo makes are written out in [NOTES.md](NOTES.md).

## The versions

| # | Name | What it changes |
| --- | --- | --- |
| 1 | Baseline | Nothing. Shot, bullet, hit, health bar. |
| 2 | The target reacts | Colour flash on hit. |
| 3 | The target moves | Knockback on hit. |
| 4 | The shooter reacts | Recoil, muzzle flash, ejected casing. |
| 5 | Timing and weight | Anticipation, easing curves, hit stop, screen shake. |
| 6 | Sound | Shot, impact and casing audio, one timbre per fighter. |
| 7 | More is not always better | Removes the casing sound. |

Versions are cumulative, so version 4 runs everything versions 1 to 3 turned on.

## Running it

Open the project folder in the Solar2D Simulator. There is nothing to install and no plugins are downloaded.

Selecting a version restarts the fight from its first loop, and the first loop is identical in every version, so compare two versions by switching between them. Only versions 6 and 7 make sound.

## Language

The demo shows Finnish by default, and the flag button switches between Finnish and English. An HTML5 build starts in English when the URL of the page it is embedded in contains `/en/`, which `plugin_pageUrl.js` reports to the demo.

## Tuning

Every value the demo uses is in `data/`. Start with `versions.lua`: it holds which layers each version switches on, plus every duration, distance, colour and easing curve those layers use.

Keep `beatVariance` in `fight.lua` at 200 ms or below. Above that, a fighter can answer a bullet that has not landed yet.

## Generated assets

The sounds and the two flag images are generated by `tools/generate_audio.py` and `tools/generate_flags.py`, and the flag script needs Pillow. The sounds are placeholders: recordings with the same file names replace them without code changes.
