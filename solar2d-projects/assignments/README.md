# Tehtäväpohjat

Tämän kansion Solar2D-projektit ovat valmiita pohjia oppituntien tehtäviin, joissa käytetään Solar2D:tä ilman ohjelmointitaitoa. Jokainen projekti toimii jo sellaisenaan. Oppitunti kertoo, mitä siihen lisätään.

Tehtäväpohjat eivät ole demoja. Niissä ei ole sellaisenaan mitään näytettävää, joten niillä ei ole sivua [oppimateriaalien verkkosivustolla](https://rosotuotanto.github.io/RG-Learning-Materials/).

Jokaisella projektilla on oma kansionsa ja oma `README.md`, joka kertoo, mihin oppituntiin projekti kuuluu ja miten sitä käytetään.

Tehtäväpohjat ja niiden kansiot:

- `character-animation` - kurssin 5 oppitunnin "Hahmo juoksemaan" pohja: hahmo seisoo ja juoksee Solar2D:ssä ensin frame-by-frame-animaationa ja sitten skeletal-animaationa. Voit vaihtaa valmiiden kuvien tilalle omat piirroksesi.
