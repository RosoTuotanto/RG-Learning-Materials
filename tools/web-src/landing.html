The Roso Games project is currently only available in Finnish, but we are working on expanding it globally and open sourcing the learning materials so that anyone can pick up game development, Lua programming, and the Solar2D engine.

Roso Games opetuspelit ja demot

Roso Games on suomalainen pelinkehityksen oppimisprojekti: kursseilla rakennetaan oikeita pelejä alusta loppuun ja opitaan samalla ohjelmointia Lualla ja Solar2D-pelimoottorilla. Löysit sivun, jolle on koottu kurssien opetuspelit ja tekniset demot pelattaviksi suoraan selaimessa. Lue lisää projektista: www.rosogames.fi.
