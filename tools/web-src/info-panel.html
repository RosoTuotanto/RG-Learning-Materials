Selaimen konsoli

Tämän sivuston pelit ja demot ovat Solar2D:n HTML5-buildeja. Ne voivat tulostaa viestejä selaimen konsoliin. Esimerkiksi kaikki print()-funktiolla tulostettu teksti näkyy siellä.

Jos pelin tai demon ikkuna näyttää mustalta tai ei reagoi mihinkään, niin katso selaimen konsolia. Se on voinut tulostaa sinne viestejä, jotka kertovat, mistä on kyse.

Näin avaat konsolin:

  • Chrome ja Edge: Ctrl + Shift + J (Windows ja Linux) tai Cmd + Option + J (macOS)
  • Firefox: Ctrl + Shift + K (Windows ja Linux) tai Cmd + Option + K (macOS)
  • Safari: ota ensin käyttöön Safari > Settings > Advanced > Show features for web developers. Sen jälkeen konsoli aukeaa näppäinyhdistelmällä Cmd + Option + C.

Mobiililaitteet

Osa peleistä ja demoista tarvitsee näppäimistöä, joten niitä ei voi pelata kokonaan puhelimella tai tabletilla.
