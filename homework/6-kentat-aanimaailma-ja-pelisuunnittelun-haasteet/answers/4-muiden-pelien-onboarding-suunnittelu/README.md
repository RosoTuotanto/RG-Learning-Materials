# Kenttäsuunnittelu: Muiden pelien onboarding-suunnittelu

[Tehtävässä](../../README.md) analysoitiin, miten valitsemasi peli opettaa pelaajan pelaamaan itseään.

Tehtävään ei ole mallivastausta, sillä vastaus riippuu valitsemastasi pelistä. Alla on kysymyksiä, joilla voit arvioida omaa analyysiasi.

## Arvioi omaa analyysiasi

Analyysi:

- Miten peli johdattaa pelaajan alkuun?
- Käyttääkö peli ohjetekstiä, visuaalisia vihjeitä, pelimekaniikoita vai näiden yhdistelmää?

Arviointi:

- Toimiiko ratkaisu hyvin?
- Missä kohtaa pelaaja voi jäädä jumiin? Jäitkö itse pelissä jumiin?

Sovellus:

- Mitä voisit oppia tästä omiin kenttiisi?
- Miten pelin onboardingia tai tutoriaaleja voitaisiin parantaa?
