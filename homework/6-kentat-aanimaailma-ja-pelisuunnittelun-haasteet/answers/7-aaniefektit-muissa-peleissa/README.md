# Äänisuunnittelu: Ääniefektit muissa peleissä

[Tehtävässä](../../README.md) analysoitiin valitsemasi pelin ääniefektejä: mikä tekee niistä hyviä tai ei niin hyviä.

Tehtävään ei ole mallivastausta, sillä vastaus riippuu valitsemastasi pelistä. Alla on kysymyksiä, joilla voit arvioida omaa analyysiasi.

## Arvioi omaa analyysiasi

Analyysi:

- Mitkä äänet toimivat pelissä hyvin?
- Mitkä äänet eivät tue pelaajan kokemusta?
- Mikä tekee näistä äänistä hyviä tai ei niin hyviä?
- Miten näitä ääniä voitaisiin parantaa tai korjata?

Arviointi:

- Mitä tapahtuisi, jos ääni poistettaisiin?
- Voisiko äänen korvata muulla palautteella, esimerkiksi visuaalisella tai haptisella palautteella? Tämä on myös saavutettavuuskysymys: peli, jonka tärkeä informaatio kulkee vain äänissä, ei toimi kaikille pelaajille.

Sovellus:

- Mitä opit toisen pelin ratkaisuista?
- Miten voisit soveltaa oppimaasi omaan peliisi?
